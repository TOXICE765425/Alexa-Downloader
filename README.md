</h2>📋 Copy All Environment Variables

BOT_TOKEN=YOUR_BOT_TOKEN
API_ID=YOUR_API_ID
API_HASH=YOUR_API_HASH
ADMIN_ID=YOUR_ADMIN_ID
CHANNEL_ID=YOUR_CHANNEL_ID
CHANNEL_URL=https://t.me/YOUR_CHANNEL
DOWNLOADER_API=https://YOUR-DOWNLOADER-API

🔑 Variables

Variable| Purpose
"BOT_TOKEN"| Telegram Bot Token
"API_ID"| Telegram API ID
"API_HASH"| Telegram API Hash
"ADMIN_ID"| Bot Admin ID
"CHANNEL_ID"| Required Channel ID
"CHANNEL_URL"| Channel URL
"DOWNLOADER_API"| Downloader API Endpoint

«🔐 Never publish your private credentials or Bot Token.»
